# Shortest Path Algorithms API

## Περιγραφή

Αυτό το project υλοποιεί τους αλγόριθμους **Dijkstra** και **Bellman-Ford** για την εύρεση της συντομότερης διαδρομής σε έναν πίνακα 16x16. Παρέχει ένα REST API μέσω FastAPI για την εκτέλεση αυτών των αλγορίθμων.
